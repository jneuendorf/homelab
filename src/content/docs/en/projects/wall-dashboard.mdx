# Wall Dashboard (MagicMirror)

A **fixed, wall-mounted tablet** showing a kid-friendly info screen — weather, today's calendar,
and custom widgets. Built on **MagicMirror²**, where everything is a module, so writing your own
widget is the normal workflow, not a hack.

> **Prerequisites:** a working Proxmox host
> ([Installing & Hardening Proxmox](/en/01-proxmox-install-harden)), and an understanding of the
> [LXC-vs-VM decision](/en/01-proxmox-install-harden#two-guest-types--pick-well).

## Why MagicMirror

- **Everything is a module** placed into a **region** (`top_left`, `bottom_bar`, …). Hundreds of
  community `MMM-*` modules exist (weather, iCal, transit, photos, RSS). Composing the screen =
  listing modules in `config.js`.
- **Custom widgets are first-class** — see [Custom widgets](#custom-widgets).
- **Display-first, not an app framework.** Touch works, but stateful apps (e.g. a todo list)
  belong in an [iframe](#embedding-other-apps-iframe).

## Platform decision

| Question                     | Answer               | Why                                                                         |
| ---------------------------- | -------------------- | --------------------------------------------------------------------------- |
| Needs Docker?                | **No**               | Plain Node app; community-scripts installs it directly.                     |
| Wants host bind-mount?       | **No**               | Calendar via network ICS, other apps via network iframe — no host ZFS data. |
| Hard isolation / own kernel? | **No**               | Internal, low-risk display app.                                             |
| **Result**                   | **unprivileged LXC** | Also a stronger default escape posture than a lone Docker container.        |

## Install (community-scripts LXC)

Find MagicMirror on [community-scripts.org](https://community-scripts.org/scripts/magicmirror) →
copy its `bash -c "$(curl -fsSL …)"` line → audit the script → run it **(host)**. It creates an
unprivileged LXC and installs Node + MagicMirror (under `/opt/magicmirror`).

## Deploy from this repo

```bash
# (Mac) — sync the repo to the host
scripts/deploy.sh root@192.168.1.10

# (host) — push modules + configs into CT 101, restart MagicMirror
/opt/homelab/projects/wall-dashboard/install.sh 101
```

Module code is overwritten on every deploy; the live config never is. The repo's sanitized
`config.js` / `custom.css` land as `*.sample` — copy them into place once:

```bash
# (host) — first deploy only
pct exec 101 -- cp /opt/magicmirror/config/config.js.sample /opt/magicmirror/config/config.js
pct exec 101 -- cp /opt/magicmirror/config/custom.css.sample /opt/magicmirror/config/custom.css
```

## Editing the live config

Your real tokens/IPs/names live only in the LXC. Its ZFS subvol is mounted on the host whether the
container runs or not, so edit the files straight over the host's SSH (other CTID/storage: derive
the path with `pct config <ctid>` + `zfs list`):

```bash
# (Mac)
zed ssh://pve/rpool/data/subvol-101-disk-0/opt/magicmirror/config
```

`custom.css` is client-side — just reload the tablet. `config.js` is read at startup — validate it
(a syntax error blanks the dashboard), restart, then reload the tablet:

```bash
ssh pve 'pct exec 101 -- node -e "require(\"/opt/magicmirror/config/config.js\"); console.log(\"config OK\")"'
ssh pve 'pct exec 101 -- systemctl restart magicmirror'
```

> **One file, self-contained callbacks.** MagicMirror compiles `config.js` from a string
> (`require-from-string`), so `require("./other.js")` has no directory to resolve against and
> crash-loops. Likewise, `items`/`badges` callbacks are **serialized and re-evaluated in the
> browser**: they may use only `ctx` and built-ins. Define helpers inside the function body, or
> the widget throws `ReferenceError`.

## iCloud calendar — read-only ICS

The `calendar` module needs a public ICS URL per calendar, in its **`https://`** form (not webcal):

- **Your own iCloud calendar** → **Mac Calendar** → right-click it → **Share Calendar** → tick
  **Public Calendar** → copy the link. Unpublish → republish rotates a leaked token.
- **A subscribed calendar** → select it → **Edit** (or File → Get Info) shows the URL.
- **Shared with you via iCloud** (not subscribed) → no public ICS; ask the owner to publish it.

Each calendar's `color` (+ optional Font-Awesome `symbol`) shows with `coloredText` /
`coloredSymbol: true` — and MMM-Routine uses it to find a child's events.

## Custom widgets

A module is a folder `modules/MMM-*/`: frontend JS (`getDom()` draws), an optional server-side
`node_helper.js` (fetches, secrets), and CSS. Socket notifications carry data between the two
halves. Each module has a self-check that runs without MagicMirror:

```bash
node projects/wall-dashboard/modules/MMM-DayParts/MMM-DayParts.test.cjs
node projects/wall-dashboard/modules/MMM-Routine/MMM-Routine.test.cjs
```

### MMM-Routine

Per-kid morning checklist at the bottom, purely client-side. Tap to check off; resets at midnight
(date-keyed `localStorage`). First to finish gets 🏆, finishing before the deadline adds ✨.

Per child, `items` and `badges` are each a fixed value or a `(ctx) => value` callback — the
[config above](#config--regions--widgets) shows both (`Kind 1` fixed, `Kind 2` dynamic). `ctx`
carries weekday, time, today's calendar events (incl. `location`), and the DayParts weather; its
JSDoc typedef gives editor autocompletion with `// @ts-check`. Done-state is keyed by item
**label**, so a callback can add or drop items without scrambling checkmarks — keep labels unique
per child. Badge ideas for the kids: [emojis.wiki/success](https://emojis.wiki/success/).

## Embedding other apps (iframe)

**[MMM-iFrame](https://github.com/alberttwong/MMM-iFrame)** drops any URL in as a tile — a todo
app, a Grafana panel, Home Assistant. The app must **allow being framed** (no `X-Frame-Options:
DENY` / `frame-ancestors 'none'`); for your own containers, configure the app or relax the header
at a reverse proxy.

```javascript
{
  module: "MMM-iFrame", position: "lower_third",
  config: { url: ["http://192.168.1.30:2021/"], width: "100%", height: "420" },
}
```

## Tablet kiosk

- **iPad:** open the URL in Safari → **Guided Access** to lock it fullscreen; Settings → Display →
  **Auto-Lock: Never**; keep on charger.
- **Android:** **Fully Kiosk Browser** (or Fullscreen Immersive) pointed at the URL; disable
  screen timeout.
- Point at the reverse-proxy HTTPS name once that's up, else `http://<lxc-ip>:8080`.
